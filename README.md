# 联苑

中国（含港澳、台湾）各地对联园地。采用 React + TypeScript + Vite + Tailwind CSS，在原有兼容工程上实现。

## 当前版本

采用用户确认的 `stitch_ (1).zip` 中 Visual Draft 1 的目录、搜索和景点视觉，沿用已经确认的 Sketch 使用路径。新版导出中的投稿页主体为空，因此根据已确认的表单字段，以同一视觉规则补齐，没有混用其他 Draft 的样式。

**可以使用**：城市定位、景点独立页、联文关键词查询、景点/城市/作者/朝代组合搜索、搜索空结果、解读展开、图片放大、复制联文、返回原城市/查询、直接地址刷新、关于与收录说明。

**投稿仍待决定**：本次要求纯前端、没有接收接口，与此前“提交进入待审核列表”的要求冲突。现保留表单填写、必填检查和关闭防误操作，明确提示未发送。没有假成功、在线审核、后台发布、数据库、登录或浏览器持久存储。待用户选择“下载投稿文件另行交付”或“保留明确演示”后再完成对应流程。

## 本地启动

建议安装 Node.js 24 LTS 和 pnpm 11。首次进入本工程目录执行：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

终端会显示实际预览地址，默认 `http://127.0.0.1:5173/`。本次交付使用 `http://127.0.0.1:5174/`，因为 5173 已被旧预览占用。

指定端口：

```sh
pnpm dev --port 5174 --strictPort
```

### 本机没有全局 Node 时

本次使用 Codex 附带的运行环境。此脚本只在当前电脑有效，不影响项目使用标准 Node / pnpm 的能力：

```sh
./scripts/local.sh dev --port 5174 --strictPort
```

关闭终端进程后预览会停止。再次运行即可恢复，工程内容始终保存在磁盘。

## 构建与检查

```sh
pnpm test
pnpm run typecheck
pnpm run build
pnpm preview --port 4173 --strictPort
```

- `test`：核对组合搜索、未知年代、关键词匹配、查询地址恢复和内容关联。
- `build`：执行 TypeScript 检查并输出 `dist/`。
- `preview`：在本地查看生产构建，确认不是只在开发模式工作。

路由使用 `/#/search?...`、`/#/place/wuhou?...` 等地址。查询参数随地址保存，无需服务端路由或浏览器存储。复制这些地址或刷新可恢复页面和查询条件；临时输入的表单内容不持久保存。

## 内容放在哪里

- `src/data.ts`：城市、景点、对联、解读、来源链接及图片说明。
- `public/images/`：会进入发布结果的本地图片。
- `src/App.tsx`：页面与导航。
- `src/components.tsx`：搜索、联句、弹窗等共用组件。
- `src/Contribution.tsx`：补充资料表单；没有接收端。
- `src/style.css`：统一的颜色、字体、间距和组件样式，以 Tailwind 为主。
- `docs/素材说明.md`：图片性质与替换说明，不作为网页资源发布。
- `AGENTS.md`、`项目记录.md`：内部维护资料，不进入 `dist/`。
- `work/before-implementation/`：实现前备份，保留早期工程和创作示例，不进入发布结果。

当前有 8 个城市目录、11 处景点、6 副有来源线索的联文。缺少资料的景点明确显示“待补充”，数量按真实工程数据计算，不代表景点实际题联总数。资料来源在每副对联展开区可访问；当前为网上资料整理，未声称已实地核验。

武侯祠配图来自用户的 Stitch 导出，是设计示意，不是题刻实拍。不把设计图中的虚构机构、数量、摄影编号或年代说明引入内容库。香港条目保留来源繁体字形；目前不做简繁自动互转。

## 一条试用路线

首页 → 点“成都” → 进入“成都武侯祠” → 展开解读和出处 → 放大示意图并关闭 → 返回目录。

然后搜索“攻心”，展开高级搜索，填“成都”“赵藩”“清” → 查看结果 → 进入景点 → 返回原搜索结果 → 刷新检查条件保留。将朝代改为“宋”会得到无结果提示，可以清除条件返回全部。
