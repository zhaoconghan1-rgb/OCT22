# 联苑

中国各地对联园地。采用 React + TypeScript + Vite + Tailwind CSS，在原有兼容工程上实现。

## 当前版本

采用用户确认的 `stitch_ (1).zip` 中 Visual Draft 1 的目录、搜索和景点视觉，沿用已经确认的 Sketch 使用路径。新版导出中的投稿页主体为空，因此根据已确认的表单字段，以同一视觉规则补齐，没有混用其他 Draft 的样式。

**可以使用**：城市定位、景点独立页、联文关键词查询、景点/城市/作者/朝代组合搜索、搜索空结果、解读展开、图片放大、复制联文、返回原城市/查询、直接地址刷新、关于与收录说明。

**投稿方式已确定**：访客无需登录，经 Formspree 私下递交资料给站主审核。只有站主明确确认的条目才由 AI 写入本地内容文件，再由站主手动部署。接收服务没有 GitHub 或网站发布权限。接收配置未完成时，入口明确显示“收件服务待启用”，不能提交。

### 启用私下投稿

站主完成 Formspree 注册及收件邮箱验证后，建立“联苑待审核投稿”表单。将该表单公开端点（格式 `https://formspree.io/f/表单ID`）交给 AI；邮箱地址、账号密码和服务后台凭据不要写入仓库。

本地复制 `.env.example` 为 `.env.local`，设置 `VITE_SUBMISSION_ENDPOINT` 后重新构建。Vercel 手动部署时设置相同环境变量并重新构建；这是公开的表单收件端点，不是密钥。前端只允许 Formspree 的 HTTPS 表单端点。服务配额、反垃圾及邮箱通知在站主自己的 Formspree 后台管理。

启用前必须提交一条明确标注的测试资料，分别核对服务接收记录、邮箱到账、网站未自动新增；目前尚未完成真实投递验收。失败、超时或限流不会显示提交成功。不要把站主邮箱直接作为前端接口。

审核流程：站主在私有收件箱查看投稿 → 将明确确认的联文及出处交给 AI → AI 整理并写入 `src/data.ts` → 站主预览、手动发布。拒绝或未确认的资料不进入公开库。无需给访客 GitHub 权限，也不开放网页发布按钮。

## 本地启动

建议安装 Node.js 24 LTS 和 pnpm 11。首次进入本工程目录执行：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

终端会显示实际预览地址，默认 `http://127.0.0.1:5173/`。本次交付使用 `http://127.0.0.1:5174/`，因为 5173 已被旧预览占用。

指定端口：

```sh
pnpm dev --port 5174 --strictPort
```

### 本机没有全局 Node 时

本次使用 Codex 附带的运行环境。此脚本只在当前电脑有效，不影响项目使用标准 Node / pnpm 的能力：

```sh
./scripts/local.sh dev --port 5174 --strictPort
```

关闭终端进程后预览会停止。再次运行即可恢复，工程内容始终保存在磁盘。

## 构建与检查

```sh
pnpm test
pnpm run typecheck
pnpm run build
pnpm preview --port 4173 --strictPort
```

- `test`：核对组合搜索、未知年代、关键词匹配、查询地址恢复和内容关联。
- `build`：执行 TypeScript 检查并输出 `dist/`。
- `preview`：在本地查看生产构建，确认不是只在开发模式工作。

路由使用 `/#/search?...`、`/#/place/wuhou?...` 等地址。查询参数随地址保存，无需服务端路由或浏览器存储。复制这些地址或刷新可恢复页面和查询条件；临时输入的表单内容不持久保存。

## 内容放在哪里

- `src/data.ts`：城市、景点、对联、解读、来源链接及图片说明。
- `public/images/`：会进入发布结果的本地图片。
- `src/App.tsx`：页面与导航。
- `src/components.tsx`：搜索、联句、弹窗等共用组件。
- `src/Contribution.tsx`：补充资料表单；由 src/submission.ts 对接 Formspree 私下收件。
- `src/style.css`：统一的颜色、字体、间距和组件样式，以 Tailwind 为主。
- `docs/素材说明.md`：图片性质与替换说明，不作为网页资源发布。
- `AGENTS.md`、`项目记录.md`：内部维护资料，不进入 `dist/`。
- `work/before-implementation/`：实现前备份，保留早期工程和创作示例，不进入发布结果。

当前有 8 个城市目录、11 处景点、23 副有来源线索的联文。缺少资料的景点明确显示“待补充”，数量按真实工程数据计算，不代表景点实际题联总数。资料来源在每副对联展开区可访问；当前为网上资料整理，未声称已实地核验。

武侯祠配图来自用户的 Stitch 导出，是设计示意，不是题刻实拍。不把设计图中的虚构机构、数量、摄影编号或年代说明引入内容库。香港条目保留来源繁体字形；目前不做简繁自动互转。

## 手动部署到 Vercel

本项目尚未上线，AI 未调用部署命令，也未推送触发部署。

由你使用自己的 Vercel 账号完成发布：选择此工程作为项目来源，框架选 Vite，安装命令为 `pnpm install --frozen-lockfile`，构建命令为 `pnpm run build`，输出目录为 `dist`，Node 版本选 24。

也可由你在本机手动使用 Vercel 官方 CLI 导入并发布此目录；账号授权、项目选择和正式发布均由你操作。选择当前目录已有 `vercel.json` 的配置即可。浏览功能无需后端；启用私下投稿需要上述 Formspree 公开端点环境变量。

只把 `dist` 内的静态网页作为发布结果；不要将整个工程根目录作为静态输出目录。`.vercelignore` 进一步排除规则、记录、备份与内部文档。后续更新由你明确选择版本后手动发布；不要为本 Workshop 配置自动推送发布流程。

部署完成后，打开首页、搜索页和景点深链接，刷新页面并检查图片；线上验证通过前，不把本地构建通过写作上线成功。
